# Frontend (React 19 + Vite 8 + Tailwind CSS 4 + TypeScript)

```bash
npm install            # or: npm ci
npm run dev            # http://localhost:5173  (proxies /api to http://127.0.0.1:8000)
npm run build          # type-check + production build -> dist/
npm run lint           # oxlint
npm test               # unit/component tests
TEST_API_BASE=http://127.0.0.1:8001/api/v1 npm test   # + end-to-end UI tests against a live API
```

Environment variables (all optional, see `.env.example`):
`VITE_API_BASE_URL`, `VITE_DEMO_MODE`, `VITE_STATION_NAME`, `VITE_DEV_API_TARGET`.

`src/theme.css` is generated by `node scripts/gen-theme.cjs` (maps Tailwind colours to CSS variables so the light theme works).
